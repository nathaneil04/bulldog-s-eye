# Public data sources used by God's Eye

- OpenSky Network — aircraft state vectors: https://opensky-network.org/api/states/all
- USGS Earthquake Hazards Program — real-time GeoJSON: https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php
- CelesTrak — GP/TLE orbital data: https://celestrak.org/NORAD/documentation/gp-data-formats.php
- Digitraffic Marine — AIS vessel locations: https://www.digitraffic.fi/en/marine-traffic/
- Digitraffic Road — traffic messages and road-weather cameras: https://www.digitraffic.fi/en/road-traffic/
- OpenStreetMap Nominatim — search/geocoding: https://nominatim.org/

Provider-specific licensing, attribution, terms, coverage, and request limits apply.

- OpenFreeMap — MapLibre-compatible public vector map tiles/styles: https://openfreemap.org/

- Community colleges / POI search: OpenStreetMap data via Nominatim `include=osm.amenity.college`. This is a mapped-POI search, not an authoritative global college registry.
